## How to Install
1. Backend must be running first in port 8000
2. Enable ```.gd``` extension in ```php.ini```
3. Run in terminal: ```composer update``` or ```composer install```.
4.  Run in terminal: `npm install -D tailwindcss postcss autoprefixer` &
`npm install`
5.  Run ````php artisan serve````.
